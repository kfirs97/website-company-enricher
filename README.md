# Website Company Enricher — Emails, Socials & Tech Stack

Turn a list of company websites into enriched leads — one row per company with emails, phones, LinkedIn & other social profiles, company name/description/logo/address and the tech stack (7,600+ technologies via the community [webappanalyzer](https://github.com/enthec/webappanalyzer) fingerprints). HTTP-only, fast, bulk-ready.

**▶ Run it on Apify (no setup, $0.01 per website, failed sites free): https://apify.com/kfirs/website-company-enricher**

Usage, input/output format and API examples: [`.actor/README.md`](.actor/README.md).
